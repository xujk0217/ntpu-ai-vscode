# 工具自動探索與按需載入

從 0.6.17 起，Agent 可按任務選擇、搜尋並載入目前主機提供的工具，不再只把工具目錄的前 40 個傳給模型。這一階段提供工具探索；沒有新增桌面 computer use 或對外提供 NTPU MCP Server。

## 一般使用

直接描述工作即可，例如「用已連接的文件工具讀取 PDF，整理結果並保留來源」。不需要手動指定工具名稱。

- 任務開始時，本機依提問關鍵字，自動載入最多三個相關、規格較小的已連線 MCP 工具。這是本機文字比對，不是額外的模型請求，也不會執行工具。
- 缺少所需能力時，Agent 使用 `search_tools` 搜尋全部可用工具與已設定 MCP。可使用中文、英文及工具原名；找不到時可換短關鍵字或翻譯後再查。這不是全網工具市集搜尋。
- Agent 使用 `describe_tool` 取得選定 MCP 工具的完整 JSON Schema，再依規格呼叫。大規格每頁最多 2,000 字元，依 `nextOffset` 與 `version` 接續；規格尚未完整取得時不開放新工具。
- 已設定但未連線的 MCP 會顯示可連線狀態。具備連線權限的主 Agent 可使用既有 `connect_mcp` 提出核准，取得連線後再搜尋、載入。不會自動安裝程式、匯入其他 Agent 的設定或讀取憑證。
- MCP 增減工具時，Agent 可使用 `search_tools` 並指定 `server`、`refresh:true`，重新取得該已連線伺服器的全部工具頁。連線、逾時、取消或分頁異常不會套用半份目錄。

輸入框的「Skills／工具設定」仍可管理 MCP 與 Skills。執行紀錄會顯示「探索可用工具」、「載入工具規格」及後續真實工具結果。

## 工具數量與脈絡

全部目錄可分頁搜尋，每頁最多 20 筆；**沒有前 40 個的可見性截斷**。模型同時保留最近六個 MCP 工具，這是提示內的快取大小，不是整個任務只能使用六種工具。載入其他工具會回報移出的名稱，需要時可重新載入。

核心檔案、Shell、搜尋、Skills 與探索工具仍直接可用。MCP 規格會依提示字元預算適量帶入，過大規格保留分頁讀取入口；內建工具沿用原本描述與範例，不假稱額外提供不存在的 JSON Schema。既有上下文整理、模型輪數、長文保存與取消機制仍適用。

## 權限與安全

探索／載入不代表核准執行。後續呼叫仍經既有權限、工作區信任、外部傳送與敏感資料檢查。MCP 的名稱、工具描述和 schema 是不可信任的資料，不能擴大權限。

唯讀子 Agent 保留原有工具白名單：即使父任務已載入其他工具，子任務也不能藉搜尋或描述取得寫入、Shell、任意外部工具或再次分派能力。各子任務獨立載入，沒有改動父任務的目錄範圍。關閉網路開關時，Exa 相關工具也不會出現在探索或目錄更新中。

工具中斷連線、被移除或規格變更後，舊載入狀態失效，必須重新探索／讀取；不會靠猜測舊參數繼續執行。配置的 URL、headers、環境變數和 SecretStorage 參照不會被探索結果帶給模型。

單一 MCP 的工具清單採 60 秒總逾時，每頁請求最多 20 秒，最多 100 頁、10,000 個工具、8 MiB metadata；超過會明確失敗，不會把不完整清單當成完整成功。沒有自動重試失敗連線，也沒有放寬既有沙箱或校方限制。

## 驗證

單元／整合測試涵蓋 240 個工具的搜尋分頁、完整大 schema 接續、規格變更／移除、載入快取、最低提示預算、核准拒絕、秘密遮蔽、網路關閉、唯讀子任務範圍、取消及原子目錄更新。真正的 localhost stdio MCP fixture 提供 75 個分頁工具，WorkspaceTools 能搜尋、載入並呼叫第 65 個工具；受控模型回覆亦驗證主 Agent 的完整工具循環。

這些測試不使用學校帳號、不呼叫真人 NTPU 模型，不代表所有第三方 MCP、認證方式或模型都已實測。
