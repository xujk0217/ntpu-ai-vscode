## 驗證界線

本機資料使用有版本的 JSON snapshots、原子寫入及檔案鎖，沒有 SQLite。資料仍會按任務需要傳給模型／外部工具；網站刪除不表示校方後端備份及稽核資料已抹除。

本版清理只追蹤執行期間自己建立的對話，不回溯批次刪除舊版對話。舊版沒有持久保存校方對話歸屬，無法安全區分它們與使用者原有對話。
