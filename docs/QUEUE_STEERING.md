# 排隊留言與任務引導

Agent 正在工作時，輸入框仍可送出新留言。預設行為是排隊：完成目前任務後，再依原順序執行後續留言。開始下一個排隊任務時會明示「開始下一則排隊留言」，區別前一任務的結語與使用者另交付的下一階段。

## 何時按「引導」

如果新留言是在補充目前工作，例如「保留現有格式」、「先修正另一個錯誤」或「這個步驟改用另一個檔案」，可按該留言旁的 **引導**。按鈕同時出現在排隊訊息泡泡與輸入框上方的佇列列。

1. 留言先顯示 **等待引導**，按鈕暫停，避免重複提交。
2. 正在生成的模型回覆、執行中的工具及必要保存完成後，主機在下一個安全邊界帶入留言。若正在產生尚未完成的分段長文件，會先完成整份文件再接收引導，避免已保存段落與新指示互相混合。
3. 實際保存並套用後，訊息顯示 **已引導目前任務**。它已成為目前工作的新條件，不會再次當作獨立排隊任務執行。

引導不會中斷正在執行的模型或 Shell，也不會把已完成的動作倒轉。需要立即停止操作時，仍應使用 **停止任務**。新留言不能授予原本沒有的權限、略過核准或繞過校方服務限制。

如果目前無法引導，按鈕會停用並提供原因；留言仍保留在佇列。含附件的留言目前保持排隊，避免在任務中途替換模型附件。編輯器選取與所附脈絡檔案會在安全邊界依既有讀取、敏感資料與核准規則處理，不能藉引導略過確認。

## 保存、暫停與恢復

尚未執行的排隊留言會保存於本機。重新載入或重開後先暫停，不會一啟動就自動執行；確認後按 **繼續佇列**，依原順序恢復。附件二進位資料不隨佇列保存；若重新載入後有附件留言，請取消該項、重新附加並送出，其他排隊留言仍保留。排隊狀態、等待引導與已套用引導各自顯示，避免將收到按鈕點擊誤認為模型已讀到新指示。

一般排隊留言可用右側移除按鈕取消。已送入引導等待的留言會停用移除，避免畫面顯示已移除但主機仍準備帶入。若任務因服務限制或取消停止，請查看實際任務狀態與保留的佇列後，再決定接續。
